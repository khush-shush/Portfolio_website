# Khushi Jyothi Hanuman | Resume Website

A personal resume and portfolio website built to showcase my work, story, leadership, and creative side in one place.

This project blends machine learning, healthcare-inspired problem solving, research, dance, leadership, and personality into a single interactive site. The goal was to make it feel polished enough for recruiters and fun enough to actually feel like me.

## About The Project

This is a static portfolio website built using HTML, CSS, and JavaScript.

It is designed as a multi-tab experience instead of a traditional one-page resume so visitors can explore different parts of my profile more naturally, including:

- Overview
- My Story
- Experience
- Projects
- Dance & Leadership
- Contact

The site uses a soft purple-rose visual theme, interactive tabs, animated stats, popup media previews, and a custom tools section to create a more dynamic experience than a standard resume page.

## Features

- Multi-tab portfolio layout
- Interactive hero section
- Experience timeline with popup certificates and attachments
- Projects section with detailed technical work
- Tools section with clickable tech stack spotlight
- Dance and leadership section with image gallery
- Animated counters and reveal-on-scroll effects
- Contact section with GitHub, LinkedIn, and email
- Fully static and easy to deploy

## Built With

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts
